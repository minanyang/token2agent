不會寫程式也能開始：只讀講義、做每站的「先試一下」與自我檢查，就能看懂 AI 系統怎麼運作（理解路線）；要動手做題目，需要基本的程式、HTTP 與 JSON 能力（實作路線）。

每一站都有兩種讀法，可以在頁首切換：**淺顯**只顯示主線，第一次讀就看得懂；**深入**會展開實作細節、推導、選修主題和進階題。

## 走完系統線，你會有什麼

系統線是各站的進階題。走完它，你會有一個已部署上線、自己每天在用的 agent，具備 RAG、工具、記憶、評估與安全防護；你也會有可以拿給別人審查的工程證據。每一站幫它長出一種能力（A 後面的數字對應站，見[代號怎麼讀](/guide/how-to-use/#代號怎麼讀)）：

| 階段 | 你的系統長出什麼 |
|---|---|
| Part III 應用基礎（A6–A8） | 串流聊天介面（Gradio、Chainlit 或 CLI 也可以）與 trace、穩定的 structured output 與 workflow、從真實 trace 長出的 golden set 與 judge |
| Part IV 知識與行動（A9–A11） | 附引用的 RAG、帶風險分級的工具與 MCP server、有預算與快取的 context builder |
| Part V Agent 系統（A12–A15） | 手寫 harness、分層記憶、trajectory eval 與 prompt 最佳化，multi-agent 只在評估勝出時保留 |
| Part VI 可信、產品、上線（A16–A18） | 安全稽核與修補、完整前端、多使用者部署與 eval 把關的發布流程 |
| Part VII 綜合實戰（A19） | 畢業專題：延伸成常駐 agent |

完整對照見[系統線 A6–A19](/projects/system-thread/#每一站長出什麼)。
