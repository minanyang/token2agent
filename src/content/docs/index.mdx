## 按主題開始學習

Token2Agent 是一份免費的 AI／LLM 工程教材，共 20 章，從大型語言模型的基本概念，到 RAG、評估、工具與 agent 部署。第一次接觸 AI，可以從 S0 開始；帶著問題來，可以先讀對應章節，遇到不熟的概念再沿章內連結補上。

| 想學什麼 | 從哪一章開始 | 這一章會回答什麼 |
|---|---|---|
| LLM 入門 | [S0 AI 系統概觀](/stages/s00-big-picture/) | 大型語言模型是什麼？模型、workflow 和 agent 怎麼組成應用？ |
| LLM API 教學 | [S6 LLM API 與應用基本功](/stages/s06-llm-api/) | 怎麼處理串流、重試、成本與 trace？ |
| LLM 評估與 Evals | [S8 Evals 方法論](/stages/s08-evals/) | 怎麼建立測試集、做錯誤分析，並校準 LLM judge？ |
| RAG 教學 | [S9 檢索與 RAG](/stages/s09-rag/) | 怎麼切塊、檢索與 rerank，並分開評估檢索和回答品質？ |
| MCP 教學 | [S10 工具與 MCP](/stages/s10-tools-mcp/) | 工具呼叫怎麼運作？怎麼寫 MCP server 並限制工具權限？ |
| Context engineering | [S11 Context engineering](/stages/s11-context-engineering/) | 每次呼叫要放哪些內容？怎麼分配 token 預算與使用快取？ |
| AI Agent 教學 | [S12 Agent loop 與 harness](/stages/s12-agent-harness/) | 怎麼手寫 agent loop，加上停止條件、權限與錯誤處理？ |
| Agent 評估 | [S14 Agent evals、資料與最佳化](/stages/s14-agent-evals/) | 怎麼評估整條執行軌跡，確認 agent 的改動真的有用？ |

不寫程式，可以走理解路線，讀講義、做每章的「先試一下」與自我檢查，了解 AI 系統怎麼運作。想動手做實作題，則需要基本程式、HTTP 與 JSON 能力。

每章可在頁首切換兩種讀法。**淺顯**顯示適合第一次閱讀的主線；**深入**另外展開實作細節、推導、選修主題與進階題。

## 走完系統專案，你會有什麼

系統專案由各章進階題串成，每章在同一個 agent 加入能力。完成後，會有一個已部署、自己每天使用，具備 RAG、工具、記憶、評估與安全防護的系統，也會留下供別人審查的工程證據。A 後面的數字對應章號，讀法見[代號怎麼讀](/guide/how-to-use/#代號怎麼讀)：

| 階段 | 你的系統長出什麼 |
|---|---|
| Part II 應用基礎（A6–A8） | 串流聊天介面（Gradio、Chainlit 或 CLI 也可以）與 trace、穩定的 structured output 與 workflow、從真實 trace 長出的 golden set 與 judge |
| Part III 知識與工具（A9–A11） | 附引用的 RAG、帶風險分級的工具與 MCP server、有預算與快取的 context builder |
| Part IV Agent 系統（A12–A15） | 手寫 harness、分層記憶、trajectory evals 與 prompt 最佳化，multi-agent 只在評估勝出時保留 |
| Part V 產品上線（A16–A18） | 安全稽核與修補、完整前端、多使用者部署與 eval 把關的發布流程 |
| Part VI 綜合實戰（A19） | 畢業專題：延伸成常駐 agent |

完整對照見[系統專案 A6–A19](/projects/system-thread/#每一章長出什麼)。
