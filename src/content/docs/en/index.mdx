## Learn by topic

Token2Agent is a free AI and LLM engineering course with 20 chapters, from large language model basics to RAG, evaluation, tools and agent deployment. Start at S0 if you are new to AI. If you have a specific question, go straight to the relevant chapter and follow its links when you need background.

| What you want to learn | Start here | Questions the chapter answers |
|---|---|---|
| LLM basics | [S0 AI Systems Overview](/en/stages/s00-big-picture/) | What is a large language model? How do models, workflows and agents fit into an application? |
| LLM API tutorial | [S6 LLM APIs and Application Basics](/en/stages/s06-llm-api/) | How do you handle streaming, retries, costs and traces? |
| LLM evaluation and evals | [S8 Evals Methodology](/en/stages/s08-evals/) | How do you build a test set, analyze failures and calibrate an LLM judge? |
| RAG tutorial | [S9 Retrieval and RAG](/en/stages/s09-rag/) | How do chunking, retrieval and reranking work, and how do you evaluate retrieval and answers separately? |
| MCP tutorial | [S10 Tools and MCP](/en/stages/s10-tools-mcp/) | How does tool calling work? How do you write an MCP server and restrict tool permissions? |
| Context engineering | [S11 Context Engineering](/en/stages/s11-context-engineering/) | What belongs in each model call? How do you budget tokens and use caching? |
| AI agent tutorial | [S12 The Agent Loop and Harness](/en/stages/s12-agent-harness/) | How do you write an agent loop with stop conditions, permissions and error handling? |
| Agent evaluation | [S14 Agent Evals, Data and Optimization](/en/stages/s14-agent-evals/) | How do you evaluate a full trajectory and check whether an agent change helps? |

You can follow the concepts route without programming: read the lectures, Try it first and self-check sections to understand how AI systems work. The hands-on routes require basic programming, HTTP and JSON.

Choose a reading mode at the top of each page. **Simple** shows the main explanation for a first read. **Deep** also opens implementation details, derivations, optional topics and advanced exercises.

## What the system project leaves you with

The advanced exercises build one system across chapters. By the end, you have a deployed agent you use daily, with RAG, tools, memory, evals and security guardrails, plus engineering evidence others can review. Each step adds a capability. The number after A matches its chapter; see [How to read the codes](/en/guide/how-to-use/#how-to-read-the-codes):

| Stage | What your system gains |
|---|---|
| Part II Applications (A6–A8) | A streaming chat UI (Gradio, Chainlit or a CLI work too) with traces, reliable structured output and workflows, and a golden set and judge grown from real traces |
| Part III Knowledge & Tools (A9–A11) | RAG with citations, tools and an MCP server with risk levels, and a context builder with a budget and caching |
| Part IV Agents (A12–A15) | A hand-written harness, layered memory, trajectory evals and prompt optimization; multi-agent stays only if it wins the eval |
| Part V Production (A16–A18) | A security audit and fixes, a complete frontend, and a multi-user deployment with an eval-gated release process |
| Part VI Capstone (A19) | The capstone: extend it into an always-on agent |

The full breakdown is in [System Project A6–A19](/en/projects/system-thread/#what-each-chapter-adds).
