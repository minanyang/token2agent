## 怎麼分享

1. Fork 這個網站的 [GitHub repo](https://github.com/minanyang/token2agent)。
2. 複製 `src/data/showcase/_template.yaml`，存成 `src/data/showcase/你的專案名.yaml`（小寫英文與連字號），照裡面的註解填好。
3. 開一個 Pull Request，標題寫「分享：專案名」。

每個專案一個檔案，只填這幾欄：

| 欄位 | 內容 |
|---|---|
| `name` | 專案名稱，40 字以內 |
| `summary` | 一句話說明它做什麼，100 字以內 |
| `url` | repo 或可以試用的網址 |
| `author` | 你的名字或暱稱，40 字以內 |
| `authorUrl` | 選填：你的個人頁面 |
| `stages` | 選填：用到哪幾章的主題，填章號（0–19），最多 6 個 |
| `added` | 開 PR 的日期 |

## 收錄條件

- 是你自己做的，或你是主要作者。
- 和 LLM 應用或 agent 有關，打開連結就看得到它做什麼：repo 有 README，或有可以試用的頁面。
- 不收：純廣告或聯盟連結、要求輸入帳號密碼或付款資料才能看介紹的頁面、內容違法或侵權的專案。
- 連結失效或專案明顯停止維護時，可能會被移除；修好後可以再開 PR。
- 送出 PR 即同意這個網站展示你填的名稱、介紹、連結與作者名稱；你的專案維持它自己的授權。

不要求附上評估數字。如果你的專案有 eval 結果、trace 或成本紀錄，寫在 README 裡會讓別人更容易從中學習（做法見 [S19 真實 agent 系統與畢業專題](/stages/s19-capstone/)）。
